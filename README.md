 GuardFlex

GuardFlex - Fliegengitter, Sonnenschutz & Plissee Lösungen

A modern, responsive web application for showcasing and managing fly screens, sun protection, and pleated blind solutions.

 Site Map

 Public Routes
- `/` - Home page with hero section, benefits, product slider, and video showcase
- `/products` - Product catalog with filtering and detailed product views
- `/services` - Services information page
- `/benefits` - Benefits and advantages page
- `/gallery` - Gallery showcasing completed projects (images and videos)
- `/history` - Company history and background
- `/contact` - Contact form and information

 Admin Routes
- `/admin` - Admin dashboard for managing products, contacts, and settings

 Technology Stack

 Frontend
- **React 18.3.1** - UI library
- **Vite 6.3.5** - Build tool and development server
- **React Router 7.9.6** - Client-side routing
- **Tailwind CSS 4.1.17** - Utility-first CSS framework
- **Lucide React 0.487.0** - Icon library

 UI Components
- **Radix UI** - Accessible component primitives
  - Dialog, Dropdown, Tabs, Select, Checkbox, and more
- **React Hook Form 7.66.1** - Form management
- **Sonner 2.0.7** - Toast notifications
- **Embla Carousel 8.6.0** - Carousel/slider component
 
  Backend
- **Node.js** (>=18.0.0) - Runtime environment
- **Express 4.22.1** - Web framework
- **MongoDB 6.20.0** - NoSQL database
- **Mongoose 8.20.1** - MongoDB object modeling

 Data Visualization
- **Recharts 2.15.4** - Chart library for admin analytics

  Development Tools
- **@vitejs/plugin-react-swc 3.10.2** - Fast React refresh with SWC
- **Nodemon 3.1.11** - Development server auto-reload

 Deployment
- **Vercel** - Hosting and serverless functions
- **Vercel Serverless Functions** - API endpoints

 Project Structure
 
  Performance Optimizations
- **Lazy Loading** - Images loaded on demand with Intersection Observer
- **Code Splitting** - Automatic chunk splitting for optimal bundle sizes
- **Image Optimization** - Responsive images with proper sizing and caching
- **Preload** - Critical resources preloaded for faster initial load

 Mobile Optimization
- Responsive design with mobile-first approach
- Touch-friendly interactions
- Optimized image loading for mobile devices
- Mobile menu with smooth animations

SEO
- Dynamic meta tags per page
- Sitemap generation
- Google Search Console integration
- Semantic HTML structure
